| 文件 | 当前状态 | 用途 |
| --- | --- | --- |
| [EPR](1.编程规范/嵌入式编程规则手册.md) | 2.0.0，已生成独立配置绑定 | ZL501 代码合规规则 |
| [EDI](2.开发指导/嵌入式程序开发指导书.md) | 2.0.0，正式发布 | ZL501 开发流程、设计资料和审核指导 |

本目录从通用版复制的 `需求与决策记录.md` 和 `完整审查记录.md` 仅保留 1.x 历史，不继承其对旧源码的批准。ZL501 项目版五个示例函数分类于 2026-10-21 获 Nan.Wang 人工批准，独立记录于本目录。EPR 的格式及哈希检查不能证明目标 DSP、TI 工具链、ABI、ISR、DMA、栈、WCET 或实时安全已验证。

在仓库根目录可执行：

```powershell
python "ZL501/1.编程规范/维护工具/coding_rules.py" check
python "ZL501/1.编程规范/维护工具/coding_rules.py" format-check `
    --clang-format "C:\Program Files\LLVM\bin\clang-format.exe"
```

后续修改函数实现、职责、调用关系或可见性时，应重新审核分类；不得自动沿用本次批准。
