# ZL501 项目版 EPR / EDI

本仓库当前仅维护 ZL501 项目版 EPR 编程规则、EDI 开发指导、格式配置、维护工具、模板、教学示例和审查记录。项目版最初由通用 1.0.2 派生，并依据《编程开发规范20261016》正文进行项目化；截图仅用作示例，原始 DOCX 不纳入仓库。通用版文件已从当前树移除，历史仍可从 Git 提交记录追溯。

ZL501 2.1.0 依据 `Nan.Wang` 分支提交 `76f04be` 适配 PIB 规则，按项目既有编号重新映射。ZL501 3.0.0 依据 `main` 提交 `3a6e1b3` 适配保护宏、文件头、注释语言和 `@category` 要求；与 2.1.0 冲突之处以 `main` 为准，EPR-DOC-007 的强制中文 `@note` 标签仍按正文保留。3.0.1 和 3.0.2 仅涉及仓库布局、路径及版本绑定，不改变规则语义或教学函数实现。

仓库级维护约束见 [AGENTS.md](AGENTS.md)，仓库结构和版本变化见 [CHANGELOG.md](CHANGELOG.md)。代码合规以 EPR 为准；开发流程、模板、资料库和审核以 EDI 为准。

`2.开发指导/需求与决策记录.md` 和 `2.开发指导/完整审查记录.md` 中继承的 1.x 内容仅作历史依据，不继承其对旧源码的批准；ZL501 项目版的人工决定以[项目审查记录](项目审查记录.md)为准。后续修改函数实现、职责、调用关系或可见性时，须重新审核分类。

从仓库根目录运行：

```powershell
python "1.编程规范/维护工具/coding_rules.py" check
python "1.编程规范/维护工具/coding_rules.py" format-check `
    --clang-format "C:\Program Files\LLVM\bin\clang-format.exe"
python "1.编程规范/维护工具/coding_rules.py" pib-check
```

本仓库不纳入原始依据文件、产品源码、临时依赖、缓存或凭据。格式和哈希检查不等于目标 TI 工具链、DSP、ABI、ISR、DMA、栈、WCET 或实时安全验证。
